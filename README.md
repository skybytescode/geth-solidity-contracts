# geth-solidity-contracts

[![CI](https://github.com/skybytescode/geth-solidity-contracts/actions/workflows/ci.yml/badge.svg)](https://github.com/skybytescode/geth-solidity-contracts/actions/workflows/ci.yml)

Five Solidity smart contracts with Go bindings generated by `abigen`, a small
Go CLI that deploys and drives them through go-ethereum, and tests that run
every contract, including the attacks it must refuse, on go-ethereum's
simulated chain.

| Contract | What it does |
|---|---|
| [`Storage`](contracts/Storage.sol) | Stores a number, emits `ValueChanged` |
| [`TokenERC20`](contracts/TokenERC20.sol) | An ERC-20 token written from scratch: transfers, allowances, `transferFrom` |
| [`MyNFT`](contracts/MyNFT.sol) | An ERC-721 collection on OpenZeppelin; only the owner mints |
| [`MyERC1155Token`](contracts/MyERC1155Token.sol) | ERC-1155 game items (GOLD, SILVER, SWORD, SHIELD): batch mint, transfer and burn |
| [`EthSender`](contracts/EthSender.sol) | A faucet: a fixed amount per address per cooldown period |

## Run the demo

```bash
make devchain                                  # a local Anvil chain on :8545
export ETH_PRIVATE_KEY=<one of the test keys Anvil prints>
go run ./cmd/ethdemo demo
```

`demo` deploys all five contracts and walks through them with a throwaway
second account, showing what works and which attacks are refused:

```
MyNFT (ERC-721)
  owner minted token #1 -> tokenURI ipfs://collection/1
  ✓ alice minting refused
  ✓ alice taking token #1 without approval refused
  after the owner approves her, alice transfers it -> owner of #1 is alice: true

EthSender (faucet: 1 ETH per address per hour)
  alice claims -> received 1.0000 ETH in total
  ✓ alice claiming again within the hour refused
```

Other commands: `ethdemo balance <address>`, `ethdemo send <address> <eth>`,
and `ethdemo txs <address> [blocks]`, which lists an account's transactions
in recent blocks. The node comes from `ETH_RPC_URL` (default
`http://127.0.0.1:8545`); keys only ever come from `ETH_PRIVATE_KEY`.

## Tests

```bash
make test        # go test -race ./...
```

The tests start go-ethereum's simulated backend in-process, so no node or
Docker is needed:

- **Storage, TokenERC20, MyNFT, EthSender, MyERC1155Token**: deploy, use, and
  attack each contract: minting without permission, taking someone else's NFT,
  spending beyond an allowance, draining the faucet, burning someone else's
  items. Each attack must fail and leave the state unchanged.
- **chain**: EIP-1559 ETH transfers, finding exactly one account's
  transactions, and key parsing that never echoes the key in errors.

[GitHub Actions](.github/workflows/ci.yml) runs gofmt, `go vet`, staticcheck
and the tests with the race detector, and recompiles the contracts with the
pinned `solc` to check that the committed bindings are up to date.

## Building the contracts

```bash
make bindings
```

Compiles `contracts/*.sol` with solc 0.8.30 (Docker) and regenerates
`bindings/` with go-ethereum's `abigen`. OpenZeppelin 5.7.0 is downloaded
from the npm registry and checked against the registry's SHA-512 first.

## History

The first version (July 2024) wrote the five contracts and drove them from Go
against a local Kurtosis devnet. This version fixes what the new tests found
and removes what should never have been committed:

| Problem | Effect |
|---|---|
| `MyNFT.transferFrom` only checked that `from` owned the token, and `mint` was public | Anyone could mint, and take anyone's NFT |
| `EthSender.sendEth` paid 42 ETH to any caller, every time | Anyone could drain the contract |
| Private keys hard-coded in Go, plus keystores and a key list in the repository | Keys published (they were local-devnet keys with no funds on mainnet or Sepolia) |
| The account-transaction scan had its filter commented out | It returned every transaction on the chain |
| Keystore path `C:\tmp\keystore`, demos switched by commenting code, `node_modules` and build output committed | Windows-only, not runnable as-is |

The keys, keystores and binaries were removed from the whole history when this
repository was created.
